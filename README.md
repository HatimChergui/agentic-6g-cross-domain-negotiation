# llm-agentic-6g-cross-domain-negotiation
About This project simulates an A2A-like negotiation between two LLM-powered agents, a RAN (Energy Saving) Agent and an Edge (Latency Assurance) Agent, to reconcile their conflicting goals. They use a small-scale digital twin (DT) to validate their proposals/counter-proposals and a collective memory with and without debiasing mechanisms.
